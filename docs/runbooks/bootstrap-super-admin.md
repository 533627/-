# 初始化首个最高管理员

该命令只用于系统首次部署。它不会开放网页注册入口，也不接受人工指定密码。

## 前置条件

1. 已设置 `DATABASE_URL`，并完成全部 Prisma 迁移。
2. 数据库中尚不存在 `SUPER_ADMIN` 用户。
3. 在受控运维终端中执行命令，避免屏幕共享、录屏或终端日志采集。

## 执行

```powershell
pnpm bootstrap:admin -- --username boss.admin --name "公司老板"
```

账号只能包含英文字母、数字、下划线和点，长度为 3–30；系统会自动转为小写。

命令成功后只输出一次账号和随机临时密码。请立即通过安全渠道保存密码；数据库只保存 Better Auth 的 scrypt 哈希，关闭终端后无法再次读取原密码。

如果最高管理员已经存在，命令会拒绝再次创建，并且不会输出新密码。后续密码重置应通过账号终端完成，不能重复运行初始化命令。
